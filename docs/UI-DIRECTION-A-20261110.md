**克莱因蓝不动**：它是产品识别，也是 Eddie 的既有约束。"A 的黑白"指中性色收敛到暖纸系，
不是把蓝去掉。

### 2.2 一处真实的对比度回归（已修）

`--accent-soft` 原 `#8A93B8` 在纯白上 3.02（刚过 3:1 线），换到暖纸后掉到 **2.83**，
跌破控件边界要求 —— `test-contrast` 当场抓到，不是事后发现。
压深到 `#727BA5`：暖纸 3.86 / bg-2 3.54。该 token 只做 1px 悬停描边、不承载文字
（`40-theme.css` 与 `test-contrast` 都有"只能描边"的断言），所以只需过 3:1。

### 2.3 排版

- `--font-display` 指向**本机衬线栈**（Cambria / Georgia / Times → 宋体），
  **不加载新字体文件**（项目硬约束：离线可用、无外部字体）。全都没有时落回 `--font-body`，
  观感降级但不出现豆腐块，与 Noto 子集是同一套降级策略。
- 标题：衬线 + 字距收紧，`.masthead h1` 44 → 46px（衬线视觉重量低于无衬线同字号，补一档）。
- 正文：行高 1.72–1.75，`.lede` 限宽 46ch、`.q-help` 52ch（原来通栏）。
  留白主要来自**行高与段距**，不是把东西缩小。
- `.q-kicker` / `.hub-kicker` / `.eyebrow` 改等宽字体 + `.16em` 字距 + 大写 —— 标本编号语法。

### 2.4 控件去容器化

| 元素 | 改动 |
|---|---|
| `.opt` | 去圆角与外框，只留上下细线；悬停不整块变色，只加深下边线 |
| `.chip` | 药丸 → 方角标签（13px + 字距） |
| `.btn` | 方角、字重 500 |
| `.pick` | 去外投影，改用一条上边线做卡头（像并排标本卡，不是浮起面板） |
| `.progress` | 分段方块 → 2px 细线，已走过部分加深 |
| `.seal` | 从 `display:none` 请回来，做成方框细边的标本编号印 |

### 2.5 深色模式

暖纸反成暖墨（`--bg: #14120E`），纸纹关闭（暗底上显脏），蓝色换 `#6E8FE8`。

## 3. 方向 B：问卷拆成一屏一问

### 3.1 为什么拆

原来"一屏合并多问"：第 2 步同屏两栏香调、第 4 步同屏场合圆盘+季节、第 5 步同屏滑块+浓度+留香。
代价是**一屏里塞 2–3 个问题，用户不知道自己在答第几题**，进度条只有 6–7 段，与实际决定数不符。

### 3.2 新步骤表

> **2026-11-11 修订**：Eddie 要求结果流程回到 9 屏，浓淡/浓度按当初预留的最小回滚点合回一屏。
> 下表已是合并后的版本（全集 9 / 家族入口 8 / 情绪入口 9）。原 10 屏版见 git 历史（`be23110`）。

| # | id | 问什么 | 家族入口 | 情绪入口 |
|---|---|---|---|---|
| 1 | `family` | 香型（轮盘） | ✓ | ✓ |
| 2 | `likedNotes` | 想要的味道 | ✓ | ✓ |
| 3 | `dislikedNotes` | 受不了的味道 | ✓ | ✓ |
| 4 | `mood` | 气质 | ✓ | ✓ |
| 5 | `occasion` | 场合 | ✓ | ✓ |
| 6 | `season` | 季节 | ✓ | ✓ |
| 7 | `concentration` | 浓淡 + 浓度（同屏 ①②③） | ✓ | ✓ |
| 8 | `dislikedFamilies` | 整族排除 | — | ✓ |
| 9 | `anchor` | 已知款 | ✓ | ✓ |
| | | **合计** | **8 屏** | **9 屏** |

合屏为什么选这一处：①②两问是同一根轴上的两个数（体感 vs 香精占比），同屏看反而更好比较——
拆开时用户在下一屏看不见上一屏拖到几档，容易答出互相矛盾的组合。香调两屏、场合/季节两屏不受影响。

「整族排除」仍只在情绪入口出现 —— 实测（`scripts/probe-step6-options.mjs`）家族入口 30 种组合里
0 种改变 top-3（候选池被 `isDominant` 过滤成 100% 本族，扣分打不中）。

### 3.3 拆屏顺带删掉的一段耦合

两栏同屏时，唯一需要**跨栏同步 DOM** 的逻辑是互斥：勾左边要把右边同名项移出并重画右栏。
拆开之后两栏永不同时存在，那段同步代码整块消失。D41（同一香调不能既喜欢又讨厌）
仍由"写同一份 state"保证 —— 约束没变，只是实现少了一处能出错的地方。

两屏候选互补：讨厌屏取 `getUsableNotes()` 的**尾部** 16 个（喜欢屏取前 16），
实测两屏首屏 16 个**零重叠**（可用香调共 58 个）。

### 3.4 三处结构性问题的修法

**① 家族入口的「整族排除」缺席**（派单点名）
该屏对家族入口不出现是正确的（0/30 无效果），但此前**没有任何地方告诉用户它去哪了** ——
情绪入口用户会发现少一屏以为出 bug，家族入口用户则根本不知道有"整族划掉"这个能力。
修法：在 `renderFamily` 里，用户选了家族之后追加一段说明：

> 「选了香型就等于排除了别的族：候选只从你选的这一族里出，所以没有"排除整族"那一题。
> 想再收窄，下一屏可以点名具体受不了的香调。」

**② 浓淡三问**（派单点名）
原来滑块 + 浓度档 + 留香同屏，三问都在说"多浓"。`be23110` 拆成第 7 屏（浓淡）与第 8 屏（浓度）；
**2026-11-11 又合回一屏**（Eddie 要求总长 9 屏，这是预留的最小回滚点）：
- 同一屏里按 ①②③ 编号：① 滑块（体感）② 浓度卡（香精占比）③ 由 ② 推断的留香（纯展示）；
- "浓淡和浓度差得有点远"的提醒恢复为屏内指代（"① 和 ② 差得有点远"），不再说"上一题"。

**③ anchor 对零基础用户的框架**（派单点名）
原 help：「可跳过。这一题比前面所有问题都准——直接拿它的香调表去找相似的气味」。
第二句对零基础的人是**反向激励**：先看到"这一题最准"、再看到品牌搜索框，
会以为必须答且必须记得名字，于是卡住或乱填。修法：
- help 改成「不记得名字就跳过 —— 这是唯一一题需要你认得瓶子的，答不出很正常。
  如果记得品牌，选一下会明显更准」（把"跳过"放最前）；
- 屏内说明从「为什么这一屏最有用」改成「不记得名字很正常」，
  并补一句"记得牌子就够了，随便挑一支风格接近的也比空着强"。

### 3.5 可分享的结果摘要卡

新面板 `[data-share="result-summary"]`，压在结果页三张大卡之后：

- 三瓶名 + 品牌 + **一句话理由**（取 `buildReasons` 的第一条，不做摘要改写 ——
  改写会把"反推到某个答案"这条硬约束改丢）；
- 用户答案摘要（气质 · 场合 · 季节 · 浓郁度），空值滤掉；
- 一行出处「从 1388 瓶里按规则打分选出，选品不调用大模型」。

为什么单独做：三张大卡纵向近 2000px，一次截图截不全，拼图也读不出"这是一组答案"。
摘要卡把关键信息压进一屏可截的范围，且截图离开站点后仍能自证。

## 4. 测试口径的变化

`test-render` 275 → **294**（+19）。关键反转：

| 原断言 | 现断言 | 为什么反转 |
|---|---|---|
| 香调屏是两栏并排 | 香调屏只有一栏 | 拆屏后两栏永不同屏 |
| 两栏各一枚计数徽标 | 该屏只有一枚 | 同上 |
| 两栏合计覆盖 ≥4 族 | 单屏 ≥3 族 + 两屏合计 ≥4 族 | 覆盖判据随拆屏重算 |
| 两栏里能找到同名 chip | 两屏首屏候选互补（零重叠） | 同屏副本已不存在 |
| 两栏互斥：勾讨厌取消喜欢 | 跨屏互斥：写同一份 state | 实现变了，约束没变 |
| 步骤全集 7 步 / 家族 6 / 情绪 7 | 全集 10 / 家族 9 / 情绪 10 | 拆屏 |
| 气质屏是「第 3 步」 | 「第 4 步」 | 新顺序 |

新增：步骤 id 两两不同（拆屏最容易复制粘贴后忘改 id）、三处拆分各自成对存在、
旧合并屏 id（notes/context/strength）不得复活、摘要卡五条。

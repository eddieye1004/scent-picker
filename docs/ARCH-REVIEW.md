**C1 扣分依据（实测）**
- S1：390 视口下 `.disc-sector.lvl1` 命中区 **39×26**，低于移动端 44×44（`_wheel4.css:13` `.wheel{width:min(88vw,var(--discw))}`）。键盘与 ARIA 均合格（`aria-checked` 六个全部正确同步），故 3 分而非更低。

**C4 扣分依据**
- S3 / S9：`choiceGrid`（`app.js:2112`）容器没有 `role="radiogroup"`，只有子按钮的 `aria-pressed`。读屏会念成「切换按钮」，而不是「单选组，第 N 项，共 M 项」。单选语义缺失。

## 五、关键取舍

第 4 步圆盘冻结后，「撤圆盘」这条最优解出局，但它的代价仍在：504×504 的盘把「② 主季节」推到 **top=849**，已压 900 视口折线。冻结意味着接受这个滚动成本，评审不再重提。

复用的第一判据是「逐字符等价」，不是「看起来像」。`polar` 与 `wheelPolar` 只差一个常量名，`annulusPath` 与 `ringPath` 归一后完全一致（各 334 字符）—— 这类重复没有任何保留理由，且合并风险接近零，应排在所有重构之前。

样式层的真正债务不是「层数多」，是 **394 条声明从未生效**。这比任何视觉问题都贵：它让「改 CSS 会生效」这个基本假设失效，每次调参都可能调在一条被覆盖的声明上。

`styles.css` 的源层在仓库外，是本次评审发现的唯一**无法从仓库内部发现**的失败模式：产物在 git 里、源层不在，测试只读产物。任何外部贡献者都会在不知情的情况下制造分叉。

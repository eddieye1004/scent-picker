## 一、佣金相关

### 结项（2026-11-08）：这条线到此为止，剩余缺口是现实的边界

用户决定收尾转别的工作。下面把**已经拿到的**和**拿不到的**分开写清，不留"以后再补"的模糊话。

| 平台 | 覆盖 | 状态 |
|---|---|---|
| 淘宝 | **637 / 1388**（45.9%） | 已接上，短链全部 `s.click.taobao.com`，带推广位归因 |
| 京东 | **0 / 1388** | 暂停 —— 搜索与批量转链接口进风控，周期 15–20 分钟滚动恢复，不是封号但无法稳定跑量 |

**淘宝剩余 751 瓶为什么不做了**：

| 原因 | 数量 | 说明 |
|---|---|---|
| 淘宝上确实没有推广计划 | 71（360 瓶区间内） | 四个查询变体（拉丁香名 / 香名首词 / 中文别名+香名 / 品牌+香名）全部 0 结果。补译名也救不回，因为索引里就没这件货 |
| 长尾品牌中文标题稀少 | 其余 | 收录的 1388 瓶里大部分是 niche 品牌，淘宝在售的多是小样、套装或压根没有 |

**结论：637 就是这条链路在"零预算、零人工逐瓶刷"前提下的实际上限。**
继续投入的边际收益极低——每补一个译名平均救回不到 1 瓶。

**这次打通的技术路径（下次要接新平台直接照抄）**：
1. `scripts/fetch-products.mjs --taobao` 调 `taobao.tbk.dg.material.optional.upgrade`（网关 `eco.taobao.com`）
2. 类目闸门：平台返回的 `category_name` 含「香水」才算数，比标题正则硬
3. 查询词策略：**只用香名，不加品牌**（淘宝是分词匹配，加词反而 0 结果）
4. `merge-product-candidates.mjs` → `gen-affiliate-links.mjs` 落表
详见 `docs/AFFILIATE-API.md`。

### ⚠️ 合规风险记录（删披露的代价，不要忘）

2026-11-08 按用户要求删掉了结果页「购买链接为推广链接」那句备注。**这不是合规上更安全的做法**：

- 中国《互联网广告管理办法》第九条要求广告"可识别"
- FTC 16 CFR 255 要求 disclosure "clear and conspicuous"

现状：页面上没有任何"这是推广链接"的可见标识，链接只剩 `rel="sponsored"` 这个机器可读信号。
若要补回来，**最小改动是购买按钮上的「广告」角标**，不必恢复整段文字。

保留的两条说明**不是**披露，删了才是骗人：
- 双渠道说明（两个按钮差在哪、价格没排序）
- 搜索兜底说明（点进去是搜索结果不是商品页）

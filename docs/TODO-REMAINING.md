**2026-11-10：品牌池法 +7（661 → 668）**。淘宝的常规路径是「按香名搜索」，但对 niche 品牌这条路很弱（搜索要每个词都命中，长香名一多就 0 条）。改用**反向路径**：先按品牌中文名把整个品牌在淘宝的在售池捞下来，再拿池子里的每一条标题去比对我库里的待补瓶。

- 四道闸门（每一条都是被真实错配逼出来的）：

### JD 可转链性（2026-11-09 晚实测，本轮最重要的新结论）

**链路本身已经端到端跑通**，不再是「封控阻塞」：

1. `localStorage.batchData` 需要模板（含 `planId`）。模板来源：在联盟默认列表**用鼠标点第一张卡片的 `.el-checkbox`**（`pg.mouse.click` 才生效），`batchData` 立刻出现 1 条。
2. 把模板克隆成 N 份、改写 `skuId/materialId/itemId/skuUrl/skuName`，写回 `localStorage` → reload → 徽标显示「已选 N /60」。
3. 「批量推广」(mouse click) → `.el-dropdown-menu` 内「我要推广」(DOM click) → 「导购媒体推广」radio → 两个 `.el-select` 用 mouse 点 wrapper（`请选择导购媒体` 选 `香水推荐器ScentPicker`；`请输入推广位` 选 `香水推荐器主站`）→ 「获取推广链接」。
4. 请求 `unionPromoteLinkService` 返回 `{"code":200,"data":"https://storage.jd.com/.../2038802551_导购媒体推广_..._<md5>.csv"}`，带 `promotionId=3110077372 / promotionType=3 / promotionTypeId=4109592421`。**403 会出现 1–2 次，第 3 次必过**。
5. CSV 是 **GBK**，9 列，字段尾带 TAB（不能 `split(',')`）。

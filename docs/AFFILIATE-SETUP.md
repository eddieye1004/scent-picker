# 佣金与购买入口：现状、操作指引、以及你手上要准备什么

> 2026-11-01 更新。对应 `docs/DECISIONS.md` D54。
> **一句话**：佣金链路代码早就写完了，但要真正生效需要你在浏览器里走一遍
> 平台注册；在此之前页面已经能给出「平台搜索」入口，零配置可用。

## 一、现在的状态（实测，不是估计）

| 档 | 触发条件 | 有佣金 | 当前是否生效 |
|---|---|---|---|
| `direct` | `target` + `pid` + `productBase` 三件套齐备 | 是 | **否** —— 三个字段都是空字符串 |
| `link` | `data/affiliate-links.json` 里有这一瓶的直达页 | 否 | **否** —— 该文件还没生成 |
| `search` | 只配了 `platform`（默认 `'jd'`） | 否 | **是** —— 结果页每张卡都有「在京东搜这一瓶 ↗」 |

实测渲染结果（1440×900，Edge headless，2026-11-01）：
三张卡各一个链接，`data-kind="search"`、`data-affiliate="false"`、
`rel="noopener noreferrer"`（**不含 sponsored**）、透明底 + 1px 灰边 + 蓝字 500 字重、
132×32px，每条下面一行 `.link-note`：
「这是京东搜索结果，不是这一瓶的商品页 —— 本站尚未接入购买链接」。

## 二、三个我无法替你做的前置判断

这三件事必须先由你决定，因为它们改变我要写的代码：

| # | 问题 | 这个答案决定什么 |
|---|---|---|
| 1 | 你打算用**京东联盟**还是**淘宝联盟**？ | 决定 `AFFILIATE.platform` 的默认值、搜索兜底走哪家、以及下面注册指引你走哪一条。京东门槛低（有京东账号即可），淘宝佣金覆盖广但必须实名+备案 |
| 2 | 这个站**有没有公开域名**，还是只在本机/局域网？ | 联盟后台申请推广位时要填推广渠道（网站/APP/社群）。没有公开域名时多数平台只批「社群/朋友圈」类目，或要求你填其他渠道 |
| 3 | 你打算**长期维护**这个站吗？ | 联盟账号有「近 90 天无有效推广则清退」类规则（各平台措辞不同）。如果只是课程项目，接上佣金反而多一个要维护的账号 |

**我的建议**：先只保留 `search` 这一档上线，把佣金当作"以后有域名了再说"。
理由是这个站的用户价值在推荐本身，不在那几毛钱佣金；而接佣金会引入
账号、审核、结算、税务四件事的持续成本。

## 三、注册指引（按平台分列，实测入口）

### 3.1 京东联盟（门槛最低）

**为什么推荐先试这家**：实测三家在无登录态下都先弹登录页，但京东的登录页
在 302 后仍保留 `ReturnUrl`（`passport.jd.com/new/login.aspx?ReturnUrl=https%3A%2F%2Fsearch.jd.com%2F...`），
用户登录完能回到自己搜的东西上。淘宝的搜索页则停在"加载中…"不完成。

| 步 | 操作 | 你需要的材料 |
|---|---|---|
| 1 | 打开 https://union.jd.com/ ，点右上「账号登录」或「扫码登录」 | 一个**已完成实名认证**的京东账号（商城账号即联盟账号，不用另注册） |
| 2 | 登录后按「免费注册账号」进入开通流程 | 身份证信息（平台自己校验，我不会接触） |
| 3 | 填推广渠道：网站 / APP / 社群 / 自媒体。**没有公开域名就选社群或自媒体** | 渠道名称、简介、（若有）域名 |
| 4 | 提交后等审核（通常 1–3 个工作日） | — |
| 5 | 审核通过后进「推广管理 → 推广位管理」，新建一个推广位 | 推广位名称（自己起，例如 `scent-picker`） |
| 6 | 复制**推广位 ID**（一串数字） | 这就是我要的 `pid` |
| 7 | 在「选品/商品库」搜一瓶香水，点「获取推广链接」 | 这一步给你 `union-click.jd.com` 或 `u.jd.com` 的短链 |

**从第 7 步的短链里能读出什么**（这是我要 `target` 模板的来源）：

京东联盟给你的短链形如 `https://u.jd.com/XXXXXXXX`，它**不是**参数化模板 ——
每个商品一条独立短链。这意味着：

- 我**没法**用一条 `target` 模板 + 香水名拼出全部 1228 瓶的链接；
- 可行的做法是**逐瓶生成**，产出一张 `id → 短链` 的表，
  也就是 `data/affiliate-links.json`（脚本已就位，见第五节）。

### 3.2 淘宝联盟（覆盖广，门槛高）

| 步 | 操作 | 说明 |
|---|---|---|
| 1 | 打开 https://pub.alimama.com/ | 首页正文只有 1 个字符，真实内容全在 `login.taobao.com` 的 iframe 里 —— 这是阿里系的标准做法，不是页面坏了 |
| 2 | 用淘宝账号登录（`fm-login-id` / `fm-login-password` / 图片验证码 / 协议勾选） | 淘宝账号必须已实名 |
| 3 | 首次进入会要求「开通淘宝客」 | 需要**实名认证 + 绑定支付宝** |
| 4 | 填推广渠道与备案信息 | 部分渠道要求**网站备案**（ICP）。没有备案域名通常只能选社群类目 |
| 5 | 审核通过后进「推广管理 → 推广位」，新建推广位 | 记下 `pid`（形如 `mm_xxx_xxx_xxx`） |
| 6 | 商品库搜香水 → 「立即推广」→ 生成推广链接 | 得到 `s.click.taobao.com` 短链或带 `pid` 的长链 |

淘宝的优势是有**参数化转链接口**（`https://s.click.taobao.com/t?e=...&pid={pid}&...`），
理论上能一条模板拼全部商品 —— 但同样需要你先有 `pid` 和商品 ID。

### 3.3 多多进宝（备选，最轻）

入口 https://jinbao.pinduoduo.com/ ，登录浮层只要**手机号 + 短信验证码**，
`#mobile` 输入框实测存在。但要拿到推广位仍需后续实名与审核。

## 四、你注册完之后，我怎么把数据写进去

**数据从哪读**：你注册完成后，从联盟后台「推广位管理」页面复制 PID，
从「获取推广链接」页面复制那一瓶香水的短链。你把这两样发给我，或者
你直接填进下面两个地方之一：

- **方式 A（推荐，改一处即可）**：在 `index.html` 的 `<head>` 里加一行
  ```html
  <script>window.SCENT_AFFILIATE = { pid: '你的PID', platform: 'jd' };</script>
  ```
  运行时覆盖，不需要改 `app.js`。但 `target` 与 `productBase` 仍需逐瓶数据。

- **方式 B**：建 `data/affiliate-links.source.json`：
  ```json
  {
    "platform": "jd",
    "links": {
      "guerlain-shalimar": "https://u.jd.com/xxxxx",
      "creed-aventus": "https://u.jd.com/yyyyy"
    }
  }
  ```
  然后跑 `node scripts/gen-affiliate-links.mjs`，它会校验协议、
  核对这些 id 在香水库里存在、产出 `data/affiliate-links.json`。

**写入网页哪些部分**：

| 写入点 | 文件 | 作用 |
|---|---|---|
| `AFFILIATE.pid` / `target` / `productBase` | `app.js`（或用方式 A 的运行时覆盖） | 启用 `direct` 档（实心蓝「去京东买这一瓶」+ 广告披露） |
| `AFFILIATE.platform` | 同上 | 决定搜索兜底与「去X看/买」文案里的平台名 |
| `data/affiliate-links.json` | 新建文件 | 启用 `link` 档（描边蓝「去京东看这一瓶」，无佣金、无广告披露） |

优先级是 `direct > link > search`，所以两张表可以同时存在，
填得越全档位越高，不需要删旧的。

## 五、阶段二的工具已就位

`scripts/gen-affiliate-links.mjs` 有两种模式：

```
# 模式 ②：读本地映射文件（推荐）
node scripts/gen-affiliate-links.mjs

# 模式 ①：走联盟开放平台 API（需要 appKey/appSecret）
JD_UNION_KEY=xxx JD_UNION_SECRET=yyy node scripts/gen-affiliate-links.mjs --api
```

实测两种模式在缺材料时都是**友好退出**（不写空文件、不崩）：

```
$ node scripts/gen-affiliate-links.mjs
香水库 1228 瓶
缺少 data/affiliate-links.source.json
  先建这个文件，结构见本脚本开头的注释；
  或者用 --api 走联盟开放平台。
  什么都不做也可以 —— 页面会退回"平台搜索页"那一档。

$ node scripts/gen-affiliate-links.mjs --api
香水库 1228 瓶
--api 模式需要环境变量 JD_UNION_KEY / JD_UNION_SECRET
  凭证只从环境变量读，不会写进任何文件。
```

**`--api` 模式的一个硬缺口**（写在这里免得你白折腾）：
京东联盟的转链接口要 `materialId`（京东 SKU），而 `data/perfumes.json`
里没有任何 SKU，只有 Scento 的溯源页。所以 `--api` 仍需要你先提供
`id → skuId` 的映射。**知道香水叫什么，不等于知道它在京东的商品编号** ——
这一层只能靠人工或后台导出补。

## 六、我不会做的事

- 不会编一个看起来像真的联盟地址填进常量（那会让"点进去能买"变成假承诺）。
- 不会替你在联盟平台注册或提交实名材料。
- 不会替你保管 appSecret —— 凭证只从环境变量读，不落任何入库文件。
- 不会给搜索跳转挂「广告」披露：它不是广告，挂了是骗人，也会让真广告披露贬值。

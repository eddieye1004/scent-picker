# lore 第 5 批 476–550 — 查证与写作规范（所有组必须严格遵守，本文件沿用第 4 批已验口径，仅改 raw 路径）

## 你要产出什么
给分配到的每瓶香水写一条中文「结果卡背书语料」条目，格式**逐字**照抄下面的模板（`###` 三级标题 + 四个字段）。

同时把**每一次搜索的原始输出**逐字存盘，作为审计证据（见「证据留痕」）。

## 条目格式（严格）
```
### {序号}. {id}（排名 {rank}）
- 名称：{品牌} {香名} {浓度全称}（{年份}）
- 背书类型：{名人同款 | 官方标语 | 经典故事 | 无可靠来源}
- 文案：{100–220 字中文，一段，不分点}
- 来源链接：{url1} ；{url2}
- 备注：{核查说明}
```

## 背书类型的判定（硬规则）
- **名人同款**：必须有主流媒体或品牌官方佐证的名人关联——品牌官方代言人／广告面孔（campaign face）、名人公开说过自己用这款。**论坛「平替/dupe」、博主推荐、模特出镜拍商业广告，都不算名人同款。**
- **官方标语**：品牌官网／官方新闻稿／官方社媒的产品文案原句、广告语。引号内必须是**原文英文**，不得翻译后当引文。
- **经典故事**：品牌的创立史、这支香的创作缘起、调香师、文化地位、有据可查的历史事件。须有可核实的出处。
- **无可靠来源**：以上三类都查不到硬证据时——`文案` 留空、`来源链接` 留空、`备注` 写清查了什么、为什么不够。

**Afnan 判例（2026-11-23 定，强制）**：若某条的唯一来源是品牌自有页、而该页对这支香通篇只有香调枚举 + 泛化形容词（没有独立广告语、没有创作缘起、没有命名故事、没有场景叙事），不得判「官方标语」——按试点批 251 Afnan 判例原形下调为：`背书类型` 写「无可靠来源」、`文案` 留空、`来源链接` 留空，`备注` 逐条写清改判理由。边界条目（页面只有一两句像是标语但整体仍是枚举）也一并写下调理由，不许整批一刀切，也不许把有独立叙事的页面误杀。

**宁留空，不编造。** 这是本项目的硬线：编一条假背书比留空严重得多。查不到就写「无可靠来源」。

## 反编造纪律（会被逐条抽验）
1. **URL 必须逐字来自搜索结果的 `URL:` 字段**，不许凭记忆手拼、不许改写 slug、不许猜路径。
2. **引号内的英文原文必须逐字复制自搜索结果的高亮／正文**，不许自己翻译回英文、不许改写措辞、不许「大意如此」加引号。
3. **人名、年份、调香师**只要来源没明说，就不写；来源互相冲突时，文案回避，在备注并列写出冲突。
4. 搜索结果 403/429/反爬拿不到正文、但**搜索摘要明确支持**的，可以采信并在备注写明「仅搜索摘要佐证」。
5. 任何一条你在备注里写不清「这句话是从哪个 URL 的哪段来的」，就不要把它写进文案。

## 证据留痕（必做）
每次搜索后，把**完整原始输出**追加到你的 raw 文件（用 pwsh 追加，不要手动转述）：

```powershell
$q = "your english query"
$o = mcporter call exa.web_search_exa query="$q" numResults=5 2>&1 | Out-String
$o | Add-Content -Path "C:\Users\16256\work\.legs\lore-b5b-20261123\search\raw-{组名}.txt" -Encoding UTF8
"`n===== QUERY: $q =====`n" | Add-Content -Path "C:\Users\16256\work\.legs\lore-b5b-20261123\search\raw-{组名}.txt" -Encoding UTF8
$o
```
（顺序无所谓，关键是 raw 文件里同时有 query 和结果全文。）

## 搜索怎么打
```powershell
mcporter call exa.web_search_exa query="Heeley Menthe Fraiche brand official notes" numResults=5
```
- 每瓶 **1–3 次**英文查询，别超。首选 `{品牌} {香名} official fragrance notes`，再按需补 `{品牌} {香名} campaign ambassador`、`{品牌} {香名} history perfumer`、`{品牌} {香名} {具体媒体} `。
- 官方站优先（`{brand}.com`），其次主流媒体（WWD、Guardian、NYT、Vogue、Cosmetics Business、PR Newswire）与香评媒体（Fragrantica 新闻、NST/nowsmellthis、Perfume Society、Bois de Jasmin）。
- Exa 的 `Highlights` 段通常已含正文原句，够用就别再 fetch。

## 文案口吻（对齐第 3 批成品）
- 中文，冷静的叙述口吻，不吹不捧，不用「令人陶醉」「完美诠释」这类营销腔。
- 有具体事实就写具体事实：年份、调香师、原句、瓶子、广告片导演/主演、品牌创立故事。
- 香调可以写，但要与给定香调一致（见你任务里的香调数据），别自己加。
- 长度 100–220 字，一段到底。

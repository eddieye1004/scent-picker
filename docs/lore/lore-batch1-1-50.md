# lore-batch1：结果卡背书语料 · 第一批（popularityRank 前 50）

调研日期：2026-11-19。数据来源：仓库 `data/perfumes.json`（只读，未改任何仓库文件），按 `popularityRank` 升序取前 50 瓶。

**统计**：50 瓶中 47 瓶有背书（名人同款 6 / 官方标语 4 / 经典故事 37），3 瓶标注「无可靠来源」文案留空。

**调研与核验规则**：
- 每瓶 1–3 次英文 WebSearch，关键来源尽量 WebFetch 读取原文核实；所有 URL 均逐字取自搜索结果或实际抓取内容，无手工拼造。
- 站点拒绝抓取（403/429）但搜索摘要明确支持的，注明「仅搜索摘要佐证」。
- 名人同款须有主流媒体或品牌官方佐证；论坛「平替/dupe」说法一律不采用。
- 「官方标语」类包含品牌官方广告语及官方产品文案原文（均在备注说明）。
- 汇编后对弱来源做了替换升级（Grand Soir、Arabians Tonka、Viking），并对关键条目做了二次抽查（Dua Lipa、Rihanna、Gucci Bloom、Ani 等均重新核实原文）。

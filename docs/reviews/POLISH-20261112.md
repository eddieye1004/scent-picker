## 1. D6：`@media print` 实测 → **发现真缺陷并修复**

### 1.1 实测方法

`scripts/probe-print.mjs`（新建）：Playwright 起真浏览器，走完流程到结果页，
`emulateMedia({ media: 'print' })` 切到打印媒体，**逐条读 `getComputedStyle`**，
并导出 PDF + PNG 供人眼复核。

不是"读 CSS 源码觉得应该有"——是渲染后读计算值。

### 1.2 改动前的实测结果（缺陷）

```json
{ "bodyBg": "rgb(250, 247, 241)",     ← 米色，不是白纸
  "rootBg": "#FAF7F1",                ← 变量没切回浅色
  "rootInk": "#14120E",
  "rootBlue": "#002fa7",              ← 这一条生效了
  "progressDisplay": "none",          ← 生效
  "actionsDisplay": "none",           ← 生效
  "buyShadow": "none" }               ← 生效
```

**一半生效、一半没生效**，这比全不生效更能定位问题。

### 1.3 根因：被条件嵌套吞掉的规则

`styles/src/40-theme.css` 里：

```css
@media (prefers-color-scheme: dark) {     /* ← 外层：只有系统开深色模式才匹配 */
  …
  @media print {                           /* ← 内层：打印 */
    :root { --bg: #ffffff; --ink: #0e0e0e; … }
  }
}
```

**只有「系统开了深色模式」且「打印」时，这条才会命中。** 浅色模式用户打印，
`--bg` 保持米色 —— 而打印纸是白的，于是正文墨色压在米色上，观感发灰。

这正好解释了 D6 为什么长期挂着「逻辑写了没跑过」：**写的时候看起来是对的，
只有真打一次才露出它是个条件嵌套错误。** 与项目里 G7（`clamp01(famHit/1.2)`
的 83.3% 天花板）同类：静态读代码看不出来。

### 1.4 修复：把它提到构建顺序的最后一层

第一版修法：把 print 块从深色模式里**移到 `40-theme.css` 末尾**。
复测结果：`--blue` 变成 `#002fa7`（生效了），但 `--bg` 仍是 `#FAF7F1`。
**仍是错的** —— 因为 `80-specimen.css` 在构建顺序里排在 40 之后，它的
`:root { --bg: #FAF7F1 }` 压过了 40 末尾的 print 块。

正确修法：放进 `styles/src/80-specimen.css`（`build-css.mjs` 的 `PARTS` 最后一项）：

```css
@media print {
  :root { --bg:#fff; --bg-2:#f5f5f5; --bg-3:#e8e8e8; --line:#d9d9d9; --hair:#e8e8e8;
          --ink:#0e0e0e; --ink-2:#3d3d3d; --ink-3:#616161;
          --edge:#767676; --stroke-ui:#767676; --stroke-l1:#bfbfbf; --stroke-l2:#767676; --stroke-l3:#0e0e0e;
          --blue:#002fa7; }
  body { background:#fff; }
}
```

连 `--stroke-*` / `--hair` 一起补，是因为 80 层同时定义了这些 token，
只改 `--bg/--ink` 会留下「白底 + 米色描边」的半吊子状态。

### 1.5 修复后的实测

```json
{ "bodyBg": "rgb(255, 255, 255)",     ← 白纸  ✅
  "rootBg": "#ffffff",                ← ✅
  "rootInk": "#0e0e0e",               ← ✅
  "buyShadow": "none",
  "buyBorder": "rgb(118, 118, 118)",  ← 边框改深灰，白底上仍可见
  "buyBg": "rgba(0, 0, 0, 0)",
  "visibleBuyLinks": 8, "pickCount": 3 }
```

截图 `_probe/print-result.png` 人眼复核：白底、黑字、按钮描边无底色、
进度条与底部操作栏已隐藏、三张候选卡完整不跨页断。

### 1.6 防回归：给 contrast 加断言（含负向验证）

`scripts/test-contrast.mjs` 新增一条：**从后往前找顶层 `@media print` 块，
要求其中含 `--bg: #fff`**。不跑浏览器，只钉字面量（观感由 probe-print 负责）。

**负向验证做了**：把 `styles.css` 里 `--bg: #ffffff` 临时改回 `#FAF7F1`，
断言立刻红：

```

```

还原后 `PASS 43  FAIL 0`。**这条断言真能抓到回归，不是摆设。**

`test-contrast` 数据：42 → **43**。
